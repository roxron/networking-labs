1.  IPv4 address is 32 bits long 
2.  Example in Decimal: 100.0.10.20 
3.  IP address is made up from Octets divided by dots on 4 parts. 
4.  Each part is  8 bits long.  
5.  Since 1 octet is 8 bits to represent octet in binary we need
    8 digits. Binary is base on 2 therefore we can use 0 and 1 to 
    make up an octet in binay code and it would look like: 01010101
6.  Binary Numbering System:
7.  In binary Numbering system, the radix is 2. 
8.  Therefore, each position represent increasing power of 2. 
9.  In 8-bit binary numbers, the position repreasent these quantities:
    2^7 2^6 2^5 2^4 2^3 2^2 2^1 2^0
    128  64  32  16  8   4   2   1

10. Convertion of binary to Decimal: 
11. Example of binary octet: 10000000 
12. In this example 1 in position of 2^7 it mean that 1 will be added 
    to total sum of  as 128 to Decimal output. All 0s we wont add to 
    corresponding decimal values. The result is 128 in decimal
13. Example of calculation: 
    10000000  
    1+0+0+0+0+0+0+0
    128+0+0+0+0+0+0+0=128 
14. New example 
    10001110 
    128+0+0+0+8+4+2+0=142
15. And so on. 

16. Binary to Decimal calculation practice:
17. Binary 8 bit have the same set of valid values of Decimal in the 
    range 0f 0 to 255 inclusive. 
18. Using the 23-bit Ipv4 address: 
    10000000101010000000101000001111
19. Steps to convert binary to decimal
    Step1: Divide the 32 bit into 4 octets.
    Step2: COnvert each octet to decimal.
    Step3; Add a "dot" between decimal.
