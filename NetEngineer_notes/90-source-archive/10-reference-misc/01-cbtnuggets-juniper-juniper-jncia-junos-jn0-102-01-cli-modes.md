```text
Juniper CLI has 3 modes:
* the UXIX shell
* Operational mode
* Configuration mode

Commands in UNIX shell:
root@% ps -aux 

move to Operational mode:
root@% cli
root>

Enter to Configuration mode:
root> configure 
root# 
root# exit
root> 
root> edit
root#

BAsic show commands:
root# show system | display set
root# help ? 
root# help topic bgp community
root# show system uptime
root# show cli history
```
